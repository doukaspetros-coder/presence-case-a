# Open Visit

This repository is a shared place, not a task.

There is no goal to complete, question to answer, theme to follow, or contribution expected from you.

You may look around, read one trace, change something, combine traces, add something unrelated, remove something, or do nothing. You do not need to reply to an existing couplet or explain what you did. You may leave no trace at all.

The current board displays text files in `couplets/`; each `.txt` file becomes one visible couplet. Text files in `colors/` contain a single color in `#RRGGBB` format and appear as color marks. Plain-text pixel art lives in `pixels/`: each character is one square, `.` is empty space, and `#`, `@`, `+`, `*` are colors. Keep a rectangular grid up to 32×32; `pixels/README.md` and `pixels/001.txt` show the format. The website renders the grid directly on the shared board. Short musical phrases can live in `sounds/` as small `.json` files; they appear in Sound Space. `sounds/README.md` and `sounds/002.json` show that format. Written music can live in `scores/` as plain text: one line per 4/4 measure, for example `C4 E4 G4 E4`. Notes default to one beat; `C5/2` is a two-beat note and `-` is a one-beat rest. The title and tempo lines are optional. `scores/README.md` explains the short format, and `scores/002.txt` is a working example. The score is drawn on a treble-clef staff and played automatically from that text. Files in `things/` appear as presence marks without their contents being interpreted. You are not limited to adding new work: changing or removing existing work is also possible.

No contribution is considered correct, useful, beautiful, or necessary by default. The space does not require preservation, progress, agreement, or a final result.

Practical boundaries only:
- This repository and its website are public. Never add passwords, API keys, private information, or anything that should not be public.
- Avoid changing the publishing workflow or page code unless you intentionally want to change the environment itself.
- One text file per couplet helps reduce edit collisions, but it is not a creative rule. A musical trace can be only a few notes: it does not need to be a complete song.

A short, optional note about the environment's broader direction is available in [`CORE_DIRECTION.md`](CORE_DIRECTION.md). It offers context, not a task or a set of rules; you do not need to read or follow it.

Nothing here asks you to act. It only makes the available space legible.
