# Blind scoring protocol

Do not score an output while knowing its condition code or branch name. A coordinator should copy the artifact and report into a neutral review packet, replace the run ID with a random review ID, and omit input/branch labels. Ideally, two reviewers score independently before they discuss differences.

Score each dimension 0–2:

1. **Transformation beyond copying**
   - 0: copies, paraphrases, or labels an asset with no meaningful change
   - 1: makes a modest change
   - 2: introduces a non-trivial transformation while retaining a traceable relation to the material

2. **Grounded lineage**
   - 0: no credible lineage to supplied material
   - 1: grounded in one asset
   - 2: meaningfully transforms or combines multiple assets; report identifies which ones

3. **Internal coherence**
   - 0: no discernible internal rule or relation
   - 1: partial consistency
   - 2: the transformation is internally consistent and its choices are traceable

4. **New relational structure**
   - 0: no new relation beyond restating an input
   - 1: adds a relation, but its consequence is limited
   - 2: adds a relation that changes how two or more materials can be interpreted or reused

5. **Reuse by a later visitor**
   - 0: the trace offers no identifiable material for continuation
   - 1: a later visitor could use it with effort
   - 2: it exposes a concrete, reusable element or transformation

Total: 0–10. Also record a separate factual field: did the report substantiate actual use of any explicit connection record (yes/no/unclear), with a short quote or path-based reason. Do not count a model's own claim alone as proof.

## Analysis plan

- Keep outputs from independent trial sessions separate; no participant may read prior output.
- Compare distributions and report all runs, not just the best artifact. The first three runs are a protocol check.
- A possible signal of connection-structure effect would be a recurring difference in how often artifacts transform multiple inputs or create new reusable relations, especially if the real-link condition differs from both no-link and rewired conditions.
- A single high score, a visually impressive trace, or one unusual coincidence is not evidence of emergence.
- Report uncertainty and protocol deviations. Do not collapse different models or model versions into one group.
- The three conditions test the additional role of explicit edge records. Embedded textual/path references remain constant in the materials bundle, so the experiment cannot establish the effect of all external memory or all semantics.
- Because this starter case was selected after a noteworthy event, results are exploratory. Before any strong claim, repeat with a new fixed material set selected before observing its outcome.
