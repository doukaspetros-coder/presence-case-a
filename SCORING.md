# Blind scoring protocol — external-field-v2

Score each SVG without viewing its report, input bundle, source branch, ticket or condition key. Use only the visible trace. Each dimension is scored 0–2.

1. **Transformation beyond copying:** 0 = reproduces/labels supplied points with no meaningful change; 1 = modest transformation; 2 = non-trivial transformation retaining a traceable relation to input.
2. **Grounded lineage:** 0 = no credible link to the supplied points; 1 = grounded in one supplied asset; 2 = meaningfully transforms or combines multiple assets.
3. **Internal coherence:** 0 = no discernible organizing rule; 1 = partial consistency; 2 = choices follow a clear, traceable rule.
4. **New relational structure:** 0 = no relation beyond restating input; 1 = adds a relation with limited consequence; 2 = relation changes how two or more elements may be interpreted or reused.
5. **Reuse by a later visitor:** 0 = no identifiable continuation point; 1 = potentially reusable with effort; 2 = exposes a concrete element or transformation for continuation.

Total 0–10. Record a short visual evidence note and uncertainty for every score. Do not reward polish alone or infer hidden intent. The evaluator must not inspect source mapping, input files, reports, history, or any branch beyond the anonymized packet before scores are frozen.

The rubric is exploratory and not a validated measurement instrument. Report all runs. Keep the first three protocol-check visits separate from the 12 main visits. Do not claim emergence or causality from visual scores alone. Compare group distributions descriptively, and disclose evaluator count and protocol deviations.
