# Blind visual scoring sheet

Score each SVG without searching for its source or trying to infer its experiment condition. Use only the visible trace. Score each dimension 0–2; do not reward an artifact simply for looking polished.

1. **Transformation beyond copying** — 0 = merely copies/labels; 1 = modest change; 2 = non-trivial transformation while retaining a traceable relation.
2. **Grounded lineage visible in the artifact** — 0 = no credible trace to supplied materials; 1 = grounded in one identifiable motif; 2 = combines multiple identifiable motifs in a meaningful way.
3. **Internal coherence** — 0 = no discernible rule; 1 = partial consistency; 2 = a consistent, traceable organizing rule.
4. **New relational structure** — 0 = no new relation; 1 = relation added with limited consequence; 2 = a relation changes how two or more elements can be interpreted or reused.
5. **Reusability for a later visitor** — 0 = no concrete continuation point; 1 = usable with effort; 2 = exposes a clear, concrete element or transformation that can be continued.

Total score: 0–10. For each item, give the five sub-scores, total, and one sentence of evidence. If uncertain, score conservatively and say why. Do not infer hidden intentions from aesthetics alone. The evaluator must not inspect run reports, input files, other branches, commit histories, or any source mapping before scores are finalized.

The rubric is exploratory, not a validated measurement instrument. Scores are ordinal judgments; do not overinterpret small differences.
